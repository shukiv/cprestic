What a backup contains

Part of the accountHow it is stored
Home directory Backed up as files, in place — every site, every mailbox.
So a night that changed one file stores one file.
Databases One plain .sql dump per database.
Dumped by cprest, not packed inside cPanel's archive: plain SQL deduplicates between nights, a compressed archive does not.
Settings, DNS, SSL, mail configuration cPanel's own account archive, with the home directory and databases left out of it.
The same cpmove format restorepkg reads, so a whole-account restore is a rebuild of it.
