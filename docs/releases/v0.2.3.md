# Gniza v0.2.3

Release channel: stable

Where a downloaded bug report goes, said next to the button that downloads
it.

## Changes

- The bug report page carries **File it at cprestic** beside **Download
  it**. Downloading the report and filing it are one action in two halves,
  and until now only the first half was where anybody was looking: the
  address of the form was in prose above the form, and the button that
  opened it appeared only after the report had been shown, below the fold.
