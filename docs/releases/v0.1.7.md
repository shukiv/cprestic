# cP:Restic v0.1.7

Release channel: stable

- Show the running build version at the bottom of every WHM plugin sidebar,
  independently of which release is available to download.
- Fix the report dialog's missing styles by keeping it inside the plugin's
  CSS scope. Use a compact, centered form with readable fields, clear preview
  actions, and bounded scrolling on small screens.
- Preserve native dialog keyboard behavior, visible focus indicators, and
  light/dark theme contrast. Preview remains required before sending a report.

This is a UI-only update. Backup, restore, account authorization, and intake
delivery behavior are unchanged from v0.1.6. Its documented restore
compatibility limitations still apply.
